# Sonali Weds Atul

A responsive, single-page wedding invitation website in Sage Green & Ivory.

## Preview locally
Open `index.html` in a browser. Internet access is needed for Google Fonts; all layout and functionality are included locally.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
3. After GitHub Pages publishes it, the URL should be `https://abhaygupta511.github.io/Sonali-weds-Atul/`.

The dates are currently set to 2026. The Tilak, Mehndi and Vidaai events intentionally do not display venue addresses; only the wedding venue is shown.
